# OpenWarden Brand Assets

The OpenWarden mark represents an open protective boundary surrounding an
inspection aperture. The aqua signal is reserved for evidence, decisions,
and allowed passage.

## Files

- `openwarden-logo.svg`: canonical transparent vector lockup with adaptive ink and outlined lettering.
- `openwarden-header.png`: transparent raster fallback used by the initial package-index release.
- `openwarden-logo-on-dark.svg`: preserved dark-background vector composition.
- `openwarden-header-on-dark.png`: preserved dark-background raster composition.
- `openwarden-mark.svg` and `openwarden-mark-dark.svg`: full-color vector marks.
- `openwarden-mark-mono-*.svg`: monochrome vector marks.
- `openwarden-lockup-*.svg`: outlined vector wordmark lockups.
- `openwarden-mark-512.png` and `openwarden-mark-1024.png`: transparent raster marks.
- `openwarden-social-preview.svg` and `.png`: 1280 x 640 repository preview.

## Palette

- Warm paper: `#F6EFE8`
- Black plum: `#1B1118`
- Ink: `#261721`
- Raspberry: `#B72B5B`
- Pink highlight: `#FF78A1`
- Electric aqua: `#55E4D2`

Use the full-color mark whenever the background permits. Use monochrome assets
when color reproduction is unavailable. Keep clear space around the mark equal
to at least one quarter of its width.
